# Cyristal N. Joseph — Portfolio

This portfolio showcases my work across cybersecurity, investigations, privacy, regulatory compliance, and research through a modern, interactive user experience. It features technical projects, publications, professional experience, and curated writing that reflect my interest in the intersection of cybersecurity, law, artificial intelligence, and emerging technologies. Each section is structured to communicate real-world capability and continuous  growth. 

---

## **✨ Key Features**

- **Animated Intro:** A smooth greeting animation that leads into the main portfolio.
- **Skills With Icons:** Clear skill categories presented with polished icon-based skill pills.
- **Publications & Research:** A dedicated section showcasing original writing, featured publications, and ongoing work exploring topics of personal and professional interest.
- **Interactive Project Cards:** Each project includes a GIF preview on the front and flips to reveal the summary and links.
- **Scrolling Project Carousel:** A horizontal, Netflix-style animation that displays selected projects.
- **Experience & Certifications:** Clean sections highlighting professional experience and verified certifications.
- **Fully Responsive Layout:** The design adapts across desktops, tablets, and mobile devices.

---


## **🛠️ Tech Stack**

- **HTML5** – Provides the structural foundation using semantic, accessible markup.  
- **CSS3** – Powers styling, responsive design, animations, and layout logic.  
- **JavaScript** – Handles interactivity, card flipping, transitions, and dynamic UI behavior.  
- **Flexbox & CSS Grid** – Creates modern, scalable layout structures across all screen sizes.  
- **Custom Assets (GIFs, Icons)** – Adds visual clarity and supports a polished, professional interface.
